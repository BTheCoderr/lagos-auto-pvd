# Lagos Auto PVD

<!-- repo-intro:start -->
**Project snapshot:** A modern Next.js website project for Lagos Auto PVD, built as a responsive local-business web presence with a maintainable App Router foundation.

**What it demonstrates:** Next.js · TypeScript · responsive business-site architecture · modern frontend tooling.
<!-- repo-intro:end -->

## Project purpose

This repository is the web application for **Lagos Auto PVD**. The focus is a clean, maintainable local-business experience rather than the default framework starter page.

## Stack

- Next.js
- React
- TypeScript
- App Router

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

Content, contact details, services, and deployment settings should be maintained in the application source rather than in starter-template copy.
